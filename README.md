# Gato's Chat Tools (gatos-chat-tools)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

Foundry VTT의 채팅창을 더 편하게 만들어 주는 모듈이에요. 메시지를 고치고 얼굴 그림을 붙이고 귓속말을 쉽게 보내고 지난 채팅을 저장해서 다시 볼 수 있어요. 어떤 게임 시스템에서도 써요.

이 폴더의 모듈은 Foundry VTT 13 버전용이에요(`master` 브랜치). 14 버전을 쓰면 `foundry-v14` 브랜치를 받아요.

## 먼저 준비할 것

이 모듈은 **gatos-lib** 모듈이 있어야 돌아가요. 둘 다 설치하고 둘 다 켜 주세요. gatos-lib가 꺼져 있으면 월드에 들어갈 때 경고가 떠요.

**Chat Images** 모듈을 쓰고 있었다면 꺼 주세요. 사진 붙이기는 이 모듈이 대신 해요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-chat-tools/master/module.json
   ```

3. "gatos-lib도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요. 이미 있으면 안 물어봐요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**와 **Gato's Chat Tools**를 둘 다 체크하고 저장해요.

주소로 설치가 안 되면 [Releases](https://github.com/snowcat0w0/gatos-chat-tools/releases) 페이지에서 `gatos-chat-tools.zip`을 받아 풀고, 그 폴더를 `Data/modules/gatos-chat-tools`에 넣어도 돼요.

## 할 수 있는 것들

### 메시지 고치기와 지우기

메시지 시간 옆에 **연필** 버튼이 생겨요. 누르면 누가 말했는지, 이름, 내용을 바꿀 수 있어요. 메시지를 우클릭해도 "메시지 수정"이 있어요.

**쓰레기통** 버튼은 묻지 않고 바로 지워요. 설정에서 "정말 지울까요?" 하고 묻게 바꿀 수 있어요.

GM은 모든 메시지를, 플레이어는 자기가 보낸 메시지만 고칠 수 있어요.

### 얼굴 그림(포트레잇)

메시지 첫 줄에 말한 캐릭터의 얼굴과 이름이 나와요. 맵에 토큰이 있으면 토큰 그림을, 없으면 캐릭터 그림을 써요. 얼굴을 누르면 캐릭터 시트가 열려요.

얼굴 크기(24~80px)와 모양(네모, 동그라미)은 내 설정이라 내 화면에서만 바뀌어요.

### 채팅창 색깔과 글자 크기

메시지 카드 색을 기본, 밝게, 어둡게, 세피아 중에 고르거나 직접 색을 골라요. 글자 크기도 바꿀 수 있어요. 내 계정에만 적용되고 다른 컴퓨터로 접속해도 그대로예요.

### 잡담 (캐릭터 말이 아닌 내 말)

채팅 맨 앞에 `!`, `` ` ``, `/pt `, 또는 `/p `를 붙이고 쓰면 캐릭터가 아니라 **나(플레이어)** 가 한 말로 나가요. 작고 옅은 카드로 표시돼서 캐릭터 대사와 바로 구분돼요.

### 루비 (글자 위에 작은 글자)

`[[약속된 승리의 검|엑스칼리버]]` 라고 쓰면 "약속된 승리의 검" 위에 "엑스칼리버"가 작게 붙어요. `[[1d20]]` 같은 주사위는 그대로예요.

### 같은 사람 메시지 묶기

같은 캐릭터가 연달아 말하면 한 묶음으로 보여요. 두 번째부터는 이름과 얼굴이 빠지고 카드가 위에 붙어요. 시간은 마우스를 올리면 보여요.

### 발화자 바 (지금 누구로 말하나)

채팅 입력창 바로 위에 "지금 이 캐릭터로 말해요"가 얼굴과 이름으로 나와요.

- **자물쇠**를 누르면 토큰 선택을 바꿔도 그 캐릭터로 고정돼요.
- **+** 로 자주 쓰는 캐릭터를 즐겨찾기에 넣고 칩을 누르면 바로 그 캐릭터가 돼요.
- **↺** 를 누르면 고정이 풀려요.

### 귓속말 보내기

채팅 아래 **🕵** 버튼을 누르면 누구한테 보낼지 고를 수 있어요. GM에게만, 고른 플레이어에게, 어떤 토큰의 주인에게, 내가 타겟한 토큰의 주인에게. 고르면 입력창 위에 "귓속말 → 누구"라고 보라색 줄이 떠요. ✕를 누르면 다시 공개로 돌아가요.

맵에서 **토큰을 클릭**하면 화면 위쪽에 작은 메뉴가 떠요. 거기서 그 토큰 주인에게 바로 귓속말을 보낼 수 있어요. 여러 명이 한 토큰을 같이 가지고 있으면 그 사람들 모두에게 가요.

플레이어끼리 귓속말을 하면 **GM도 항상 같이 받아요.** 귓속말은 토큰 위 말풍선으로 뜨지 않아요. 다른 사람이 보면 안 되니까요.

### 사진 붙이기

채팅 입력창에 사진을 **붙여넣기(Ctrl+V)** 하거나 **끌어다 놓으면** 올라가요. 채팅 아래 **그림 버튼**으로 골라도 돼요. 글 없이 Enter를 치면 사진만 가고 글이 있으면 사진 아래에 글이 붙어요.

큰 사진은 자동으로 작게 줄여서 올려요. 채팅의 사진을 누르면 크게 봐요. 사진은 서버의 `uploaded-chat-images` 폴더에 저장돼요. 파일 올리기 권한이 없는 사람은 이 기능을 못 써요.

### 지난 채팅 저장하기(아카이브)와 찾기

채팅 아래 **상자 아이콘**을 누르면 창이 열려요.

- GM은 지금까지의 채팅을 저장할 수 있어요. 전체, 오늘, 최근 7일처럼 범위를 골라요. 저장하면서 채팅창을 비울 수도 있어요.
- 모두가 저장된 채팅을 열어 볼 수 있어요. 단어로 찾고 말한 사람이나 날짜로 걸러요. 찾은 단어는 노랗게 표시돼요.
- 플레이어에게는 자기한테 온 게 아닌 귓속말이 안 보여요.
- **세션 시작 / 세션 종료** 버튼으로 "제3회 모험"처럼 회차 단위로 묶어 저장할 수 있어요. 설정을 켜면 채팅에도 시작과 끝 표시가 남아요.
- **자동 저장**을 켜 두면 메시지가 정해 둔 수보다 많아질 때 GM 컴퓨터가 알아서 저장해요.
- 저장한 채팅은 **내보내기**로 파일을 만들 수 있어요. 글자만(TXT), 웹 페이지(HTML), 묶음(ZIP), Markdown, 또는 월드 안의 저널로요.
- 다른 월드에서 저장한 파일을 **가져오기**로 불러오거나, 여러 개를 **병합**으로 하나로 합칠 수 있어요(GM).
- **선택** 모드를 켜면 메시지에 체크박스가 생겨서 고른 것만 내보내거나 지울 수 있어요.

저장 파일은 서버의 `Data/worlds/<월드 이름>/chat-archives/` 폴더에 들어가요. 목록에서 지워도 파일은 서버에 남아요. 필요하면 폴더에서 직접 지우세요.

### 북마크와 하이라이트

메시지를 우클릭해요.

- **북마크**: 나만 보는 별표(★)예요. 아카이브로 옮겨져도 남아요.
- **하이라이트**: 모두에게 금색으로 보여요. GM이나 글쓴이만 할 수 있어요.

### 순서 바꾸기와 복제 (GM)

메시지를 우클릭하면 **위로 이동**, **아래로 이동**, **복제**가 있어요. 수정 창에서 **보낸 시각**을 바꾸면 그 시각 자리로 옮겨가요.

## 설정

**게임 설정 → 모듈 설정 → Gato's Chat Tools**에서 바꿔요. "나만"은 내 화면에만 적용되고 "월드"는 GM이 바꾸면 모두에게 적용돼요.

| 설정 | 누구 | 처음 값 |
|---|---|---|
| 쓰레기통 버튼으로 바로 삭제 | 월드 | 켬 |
| 플레이어가 자기 메시지 수정·삭제 | 월드 | 켬 |
| 메시지에 수정·삭제 버튼 표시 | 나만 | 켬 |
| 아카이브에서 플레이어에게 비밀 메시지 숨김 | 월드 | 켬 |
| 얼굴 그림 표시 / 크기 / 모양 | 나만 | 켬 / 40px / 네모 |
| 채팅창 테마 / 글자 크기 | 나만(계정) | 기본 / 시스템 크기 |
| 잡담 시작 글자 / 글자 크기 / 배경 밝기 | 나만 | `/p` / 12px / 0.7 |
| 연속 메시지 묶기 / 묶기 최대 간격(분) | 나만 | 켬 / 0(제한 없음) |
| 발화자 바 표시 / 즐겨찾기 표시 | 나만 | 켬 / 켬 |
| 세션 시작·종료를 채팅에 알림 | 월드 | 켬 |
| 자동 저장 기준 메시지 수 / 남길 최근 메시지 수 | 월드 | 0(끔) / 50 |
| GM 접속 시 지난 기록 자동 저장 | 월드 | 끔 |
| 사진 첨부 / 사진 저장 폴더 | 월드 | 켬 / `uploaded-chat-images` |
| 토큰 클릭 시 귓속말 메뉴 | 나만 | 켬 |

## 매크로나 다른 모듈을 만드는 사람에게

`game.modules.get("gatos-chat-tools").api` 안에 함수들이 있어요. 예를 들어 `api.openViewer()`는 아카이브 창을 열어요. 전체 목록과 다른 모듈이 끼어들 수 있는 훅(`gct…`로 시작)은 `scripts/module.js`를 열어 보세요.
