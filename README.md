# Gato's Chat Tools

Foundry VTT v14용, 시스템 무관 채팅 도구 모듈입니다. (v13용은 별도 브랜치/설치본을 쓰세요.)

**요구 모듈**(0.6.0부터): [gatos-lib](../gatos-lib/README.md). 설치·활성화돼 있어야 하며, 설치만 되고 비활성이면 ready에서 경고가 뜹니다. 기능·API·훅·설정 키·lang 키·플래그·아카이브 형식은 0.5.2와 같습니다(gatos-visual-novel 호환 표면 체크리스트: gatos-lib/CHECKLIST-chat-tools-vn.md).

## 기능

### 메시지 수정 / 삭제
- 채팅 메시지 머리말(시간 옆)에 **연필(수정)** 버튼이 생깁니다. 우클릭 메뉴에도 "메시지 수정"이 추가됩니다.
- 수정 창에서 **화자(액터)**, **표시 이름**, **플레이버 텍스트**, **내용(HTML)** 을 바꿀 수 있습니다.
- **쓰레기통** 버튼은 확인 창 없이 바로 삭제합니다 (설정에서 끄면 확인 창을 띄움).
- GM은 모든 메시지, 플레이어는 자기가 보낸 메시지만 수정/삭제할 수 있습니다 (설정으로 플레이어 수정 비활성화 가능).

### 포트레잇
- 채팅 카드 첫 줄에 화자(액터)의 이미지·이름·시간·수정/삭제 아이콘을 한 줄로 놓고, 본문은 그 아래에서 카드 전체 폭을 씁니다(뷰어 카드와 HTML 내보내기도 같은 배치). 장면에 토큰이 있으면 토큰 이미지, 토큰이 맵에 없으면 액터 초상화를 씁니다. 액터가 없는 메시지(OOC 등)에는 표시하지 않습니다.
- 이미지는 메시지가 올라올 때 메시지에 저장되므로, 나중에 토큰·액터 이미지를 바꿔도 이미 올라온 메시지는 그대로입니다. 수정 창에서 화자를 바꾸면 그 시점의 이미지로 다시 저장됩니다. 모듈 설치 전 메시지는 현재 이미지를 씁니다.
- 크기(24~80px)·모양(사각/원형)·표시 여부는 클라이언트 설정이라 플레이어마다 다르게 둘 수 있습니다. 볼 권한이 있는 액터면 포트레잇 클릭으로 시트가 열립니다.
- 아카이브 뷰어와 HTML 내보내기에도 같은 이미지가 들어갑니다 (이 기능 추가 전에 저장한 아카이브에는 없음).

### 채팅창 테마 · 글자 크기
- 채팅 메시지 카드의 배경색·글자색을 테마(기본/밝게/어둡게/세피아/사용자 지정)로 고를 수 있습니다. 사용자 지정이면 배경색·글자색을 직접 고릅니다. 귓속말·비공개 굴림·이모트는 배경에 원래 색이 살짝 섞이고 테두리 색은 그대로라 구분됩니다. 잡담·세션 표시는 자체 색을 유지합니다.
- 채팅 기본 글자 크기(10~24px, 기본은 시스템 크기)는 채팅 메시지와 입력창에 적용됩니다. 잡담은 잡담 글자 크기를 따릅니다.
- 모두 클라이언트 설정이라 플레이어마다 다르게 둘 수 있습니다.

### 잡담 (Chitchat)
- 채팅 입력을 `/pt `, `` ` ``, `!` 또는 설정한 추가 문자(기본 `/p `)로 시작하면 캐릭터 대사와 구분되는 **잡담**으로 보냅니다. 토큰 선택이나 발화자 고정과 관계없이 항상 **보낸 플레이어(사용자) 이름**으로 표시되며, 사용자 색으로 옅게 칠한 작은 카드에 "이름 내용" 한 줄로 나오고 포트레잇은 붙지 않습니다. 잡담 수정 창에서는 화자를 바꿀 수 없습니다.
- 입력창에 트리거를 치면 발화자 바가 "잡담" 표시로 바뀌어 어떤 메시지가 나갈지 알 수 있습니다.
- 글자 크기·배경 밝기·이름 뒤 줄바꿈은 클라이언트 설정, OOC/기타 스타일 선택은 월드 설정입니다.

### 루비 표기
- 채팅 어디서나 `[[약속된 승리의 검|엑스칼리버]]` 처럼 적으면 "약속된 승리의 검" 위에 "엑스칼리버"가 작게 붙는 루비(후리가나)로 표시됩니다. 일반 대사, 잡담, 매크로로 만든 메시지 모두 적용됩니다.
- 메시지는 `<ruby>` HTML로 저장되므로 모든 사용자, 아카이브, HTML 내보내기에 그대로 나오고, TXT 내보내기에서는 "약속된 승리의 검(엑스칼리버)"로 나옵니다. 수정 창에서는 다시 `[[...|...]]` 표기로 보여줍니다.
- `|` 가 없는 `[[1d20]]` 같은 인라인 굴림은 건드리지 않습니다.

### 메시지 그룹화
- 같은 사용자·화자(·스타일·귓속말 대상)가 연속해서 보낸 메시지를 한 묶음으로 표시합니다. 이어지는 메시지는 이름과 포트레잇을 생략하고 카드가 위 카드에 붙습니다. 시간은 마우스를 올리면 보입니다.
- 잡담도 연속이면 한 묶음이 됩니다. "묶기 최대 간격(분)"을 두면 그 이상 떨어진 메시지는 새 묶음으로 시작합니다. 모두 클라이언트 설정입니다.

### 발화자 바
- 채팅 입력창 바로 위에 지금 어떤 화자(토큰 → 배정 캐릭터 → 사용자 순)로 말하게 될지 초상화와 이름으로 표시합니다. 초상화를 클릭하면 시트가 열립니다.
- 자물쇠를 누르면 현재 화자가 **고정**되어 토큰 선택을 바꿔도 그 화자로 발신됩니다 (잡담은 제외).
- 즐겨찾기 줄의 `+`로 현재 화자를 등록하고, 칩을 누르면 그 화자로 바로 고정됩니다. `↺`는 기본 발화자로 돌아갑니다(고정 해제). 칩은 초상화 또는 이름으로 표시할 수 있습니다.

### 세션 로그
- 뷰어 왼쪽 위 **세션 시작**(GM)으로 회차 번호(자동으로 다음 번호)와 제목을 정하면, 그때부터의 채팅이 그 세션으로 묶입니다. 진행 중에는 상자에 "제3회 「제목」 · 시작 시각 · 메시지 수"가 보입니다.
- **세션 종료·저장**을 누르면 시작부터 지금까지를 한 번에 아카이브로 저장합니다(저장 후 로그에서 삭제 선택 가능). 아카이브 목록의 **세션 로그** 묶음에 `#3` 배지와 함께 번호순으로 정리됩니다.
- 설정 "세션 시작/종료를 채팅에 알림"이 켜져 있으면 채팅에 시작·종료 표시 카드가 남습니다(검색 종류 "세션 표시"로 찾을 수 있음).

### 자동 아카이브
- **채팅 메시지 수 기준**(월드 설정, 0=끔): 로그가 그 수를 넘으면 GM 클라이언트(접속한 GM 한 명)가 "마지막 아카이브 이후" 메시지를 자동 저장하고, 저장된 메시지를 로그에서 지우되 최근 메시지 N개(설정)는 남깁니다. 세션 진행 중에는 쉬고 세션 종료 때 저장됩니다.
- **GM 접속 시 이전 기록 자동 저장**(월드 설정, 기본 끔): GM이 접속했을 때 아직 저장 안 된 메시지 중 가장 최근 것이 3시간 이상 지났다면, 지난 접속분으로 보고 자동 저장합니다. 월드가 꺼지는 순간은 모듈이 안정적으로 잡을 수 없어 다음 접속 때 처리하는 방식입니다.
- 자동으로 만든 아카이브에는 `A` 배지가 붙습니다.

### 북마크 · 하이라이트
- 메시지 우클릭 → **북마크**: 나만 보는 표시입니다(사용자별 저장). 채팅 카드 시간 옆에 ★이 붙고, 뷰어에서는 카드의 ☆을 눌러 켜고 끌 수 있습니다. 메시지가 아카이브로 옮겨져도 북마크는 유지됩니다.
- 메시지 우클릭 → **하이라이트**(GM 또는 작성자): 모든 사용자에게 금색으로 표시되고, 아카이브와 내보내기에도 남습니다.

### 메시지 순서 · 복제 (GM)
- 메시지 우클릭 → **위로 이동 / 아래로 이동**: 이웃 메시지와 순서를 바꿉니다. **복제**: 원본 바로 아래에 같은 메시지(화자·포트레잇 포함)를 하나 더 만듭니다.
- 수정 창의 **보낸 시각**(GM 전용)을 바꾸면 메시지가 그 시각 위치로 옮겨집니다. 모든 사용자 화면에 바로 반영되고, 새로고침 후에도 유지됩니다.

### 귓속말 대상
- 채팅 컨트롤 줄(메시지 공개 범위 버튼 옆)의 🕵 버튼으로 귓속말 대상을 고릅니다. 우클릭하면 바로 공개로 돌아갑니다. 키 설정에 "귓속말 대상" 단축키를 지정할 수도 있습니다.
  - **공개**, **GM에게만**, **플레이어 지정**(여러 명 체크), **특정 토큰의 소유자**(현재 장면의 토큰 목록에서 고르며 소유자 이름이 함께 보임), **내가 타겟한 토큰의 소유자**, **선택한 토큰의 소유자**.
  - 대상이 정해져 있으면 입력창 바로 위에 보라색 "귓속말 → 받을 사람" 줄이 뜹니다. ✕로 공개로 되돌리고, 이름을 누르면 다시 고릅니다. "한 번 보낸 뒤 공개로 되돌리기"를 켜면 한 번만 적용됩니다.
- 대상이 정해져 있으면 채팅 컨트롤의 메시지 공개 범위(공개/GM/블라인드/자신)보다 이 대상이 우선합니다.
- 받는 사람은 **보내는 순간의 소유권**으로 정해집니다. 나중에 소유권이 바뀌어도 이미 보낸 메시지의 수신자는 바뀌지 않습니다. 소유자가 없으면 경고를 띄우고 GM에게만 보냅니다.
- 입력창에 쓰는 일반 메시지와 잡담에 적용되며, `/w`, `/r` 같은 명령어는 원래대로 동작합니다. 메시지 카드의 "받는 사람" 줄 뒤에 "(고블린 소유자)"처럼 어떤 대상으로 보냈는지가 붙습니다.
- 귓속말에는 토큰 위 말풍선을 띄우지 않습니다. Foundry는 귓속말 내용을 수신자가 아닌 사람의 클라이언트에도 보내고 말풍선은 수신 여부를 확인하지 않고 띄우기 때문에, 캐릭터로 보낸 귓속말이 말풍선으로 새어 나가는 것을 막기 위해서입니다.
- **플레이어가 다른 플레이어에게 보내는 귓속말에는 GM이 항상 수신자로 추가됩니다.** 이 버튼뿐 아니라 Foundry 기본 `/w`나 매크로로 보낸 경우도 같습니다. 자기 자신에게만 보내는 비공개 굴림은 그대로 둡니다.
- **토큰 클릭 메뉴**: 토큰 레이어에서 토큰을 클릭하면 화면 위쪽 가운데에 반투명 메뉴가 뜹니다(토큰 이미지·이름·현재 소유자). **귓속말 보내기**를 누르면 입력칸이 열리고, Enter로 그 토큰의 소유자(+GM)에게 바로 보냅니다. 📌는 채팅 귓속말 대상을 그 토큰으로 고정합니다. 메뉴가 뜨는 토큰은 ① 나 말고 다른 플레이어 소유자가 있는 토큰(내 PC라도 공동 소유자가 있으면 포함), ② 플레이어라면 자기 지정 PC가 아닌 모든 토큰(다른 플레이어 소유자가 없으면 GM에게만 감)입니다. GM에게는 지정 PC가 없으므로 플레이어 소유자가 있는 토큰에만 뜨고, 몬스터를 옮길 때는 나타나지 않습니다.
  - **은닉 진행**: 여러 사람이 같은 토큰(예: 비밀 NPC)을 소유하면, 그 토큰을 클릭해 소유자 모두(+GM)에게 귓속말을 보낼 수 있습니다. 그 토큰을 소유한 플레이어가 보내면 토큰 이름으로 말합니다. 토큰으로 보낸 귓속말 카드에는 ↩ 버튼이 붙어, 받은 사람이 같은 토큰 소유자에게 바로 답장할 수 있습니다. 빈 곳 클릭, ✕, Esc로 닫힙니다. 플레이어도 남의 토큰을 클릭해 쓸 수 있습니다(선택은 되지 않고 메뉴만 뜸). 메뉴로 보낸 귓속말은 채팅 대상 설정을 바꾸지 않으며, GM이 그 토큰을 선택한 상태여도 그 토큰 이름이 아니라 자기 이름(또는 배정 캐릭터)으로 보냅니다. 설정 "토큰 클릭 시 상단 귓속말 메뉴"로 끌 수 있습니다.
- API: `game.modules.get("gatos-chat-tools").api.whisper` (`setWhisperTarget({mode:"token", sceneId, tokenId, tokenName})`, `resolveRecipients()`, `tokenOwners(tokenDoc)` 등).

### 채팅 아카이브 / 검색
- 채팅 입력창 아래 컨트롤 바의 **상자 아이콘**(채팅 아카이브 / 검색)으로 엽니다. 매크로: `game.modules.get("gatos-chat-tools").api.openViewer()`
- **GM**: "현재 채팅 아카이브 저장" → 이름, 범위(전체 / 마지막 아카이브 이후 / 오늘 / 최근 7·30일 / 날짜 직접 지정), 저장 후 채팅 로그에서 삭제 여부를 정해 저장합니다.
  - 파일은 `Data/worlds/<월드id>/chat-archives/<id>.json` 에 저장되고, 목록은 월드 설정에 기록됩니다.
- **모든 사용자**: 왼쪽 목록에서 "현재 채팅 로그" 또는 저장된 아카이브를 골라 보고, 검색어(내용·화자·플레이버·굴림 공식), 화자, 날짜 범위로 필터할 수 있습니다. 검색어는 노란색으로 강조됩니다.
  - 플레이어에게는 자기에게 온 것이 아닌 귓속말과 비공개 굴림이 숨겨집니다 (설정 "아카이브에서 플레이어에게 비밀 메시지 숨김").
  - 현재 채팅 로그에서는 메시지 옆 화살표로 채팅창의 해당 메시지로 이동(또는 팝아웃)합니다.
- **고급 검색**: 사용자(플레이어) 필터, 종류 필터(굴림 / 귓속말·비공개 / 잡담 / 내 북마크 / 하이라이트 / 세션 표시), 검색창 옆 `.*` 체크로 정규식 검색(대소문자 무시, 잘못된 식이면 빨간 테두리). `▲ ▼`(또는 검색창에서 Enter / Shift+Enter)로 일치 위치를 차례로 이동하며 "현재/전체"를 보여줍니다.
- **선택 모드**: 툴바의 "선택"을 켜면 카드마다 체크박스가 생깁니다. Shift+클릭으로 범위 선택, "결과 전체 선택", 그리고 선택한 메시지만 **북마크 / 내보내기 / 삭제**(현재 로그에서만, 지울 권한이 있는 메시지만)할 수 있습니다.
- **아카이브 파일 관리**:
  - 각 아카이브의 ⬇ **JSON 받기**(모든 사용자): 원본 아카이브 JSON을 내려받습니다(백업·다른 월드로 옮기기).
  - **가져오기**(GM): 아카이브 JSON(다른 월드 것 포함, ZIP의 `*.log.json`도 가능)을 새 아카이브로 등록합니다. `I` 배지. ZIP의 `*.log.json`은 이미지 경로가 번들 기준이라 Foundry 안에서는 그림이 안 보일 수 있으니, 가능하면 "JSON 받기"로 받은 파일을 쓰세요.
  - **병합**(GM): 아카이브 여러 개를 골라 하나로 합칩니다(같은 메시지는 한 번만, 시간순). 원본을 목록에서 뺄지 고를 수 있습니다. `M` 배지.
  - **삭제**(GM): 목록에서 지울 때 "서버의 아카이브 파일 내용도 비우기"를 체크하면 파일을 작은 빈 표식으로 덮어씁니다. Foundry에는 파일 삭제 기능이 없어 빈 파일 자체는 서버 폴더에 남습니다.
- **잡담 포함** 체크: 뷰어 툴바의 체크를 끄면 잡담이 목록과 내보내기에서 빠집니다. 내보내기 창에도 같은 체크가 있습니다.
- **내보내기**: 툴바의 "내보내기"에서 형식을 고릅니다. 모두 지금 보이는(필터된) 메시지가 대상입니다.
  - **TXT** — 순수 텍스트.
  - **HTML 단일 파일** — CSS와 이미지(포트레잇 포함)를 데이터 URI로 내장한 파일 하나. 어디서나 바로 열립니다.
  - **ZIP** — `chat-log-날짜-월드.html` + `chat-log-날짜-월드.log.json` + `chat-styles.css` + `images/` + `portraits/`. 여러 회차를 같은 폴더에 풀면 CSS·이미지를 공유하고 로그 파일은 회차마다 따로 남습니다. 외부 라이브러리 없이 모듈 자체 zip 작성기를 씁니다. `.log.json`은 직렬화한 메시지(이미지 경로는 번들 기준 상대 경로)로, 나중에 로그를 재생하는 도구가 읽을 수 있습니다.
  - **폴더에 저장** — 처음 한 번 폴더를 고르면 이후 그 폴더에 HTML·CSS·이미지를 바로 씁니다 (File System Access API: Chrome·Edge·Foundry 앱). 월드별로 폴더를 기억하며, 내보내기 창의 링크로 초기화할 수 있습니다.
  - **새 창에서 보기** — 파일 없이 브라우저 새 창에 표시.
  - **Markdown** — `.md` 텍스트(날짜별 `##`, 잡담은 목록, 세션 표시는 구분선). 디스코드·노션·옵시디언에 붙여 넣기 좋습니다.
  - **저널 엔트리** — 월드 안에 저널을 만들고 날짜마다 페이지 하나씩 로그를 넣습니다. "플레이어에게 공개"를 켜면 관찰자 권한으로 만듭니다.
  - 옵션: 잡담 포함, 귓속말·비공개 포함, 포트레잇 포함, **사용자 색상 표시**(HTML 계열: 카드 왼쪽 띠와 이름 앞 점), **주사위 상세 포함**(HTML은 주사위 눈을 펼친 채로, TXT/Markdown은 "2d6 + 3 = 8 (2d6: 2, 3)" 줄 추가). 형식에 해당하지 않는 옵션은 숨겨집니다. 그룹화 설정이 켜져 있으면 내보낸 HTML도 연속 메시지를 묶어 보여줍니다.
- **GM: 날짜로 메시지 삭제**: 뷰어 왼쪽의 "날짜로 메시지 삭제" → 범위(마지막 아카이브까지 / 전체 / 오늘 / 최근 7·30일 / 날짜 직접 지정)를 고르면 삭제될 개수를 미리 보여주고, 확인 창을 거쳐 현재 채팅 로그에서 지웁니다. 아카이브 파일은 건드리지 않습니다. 매크로: `game.modules.get("gatos-chat-tools").api.openDeleteDialog()`

### 채팅 이미지 (0.4.0, Chat Images 모듈 대체)
Chat Images 모듈이 하던 일을 이 모듈이 직접 합니다. **Chat Images 모듈은 꺼 주세요.** 켜져 있는 동안은 이 기능이 쉬고 아래 호환 패치가 대신 동작하며, GM에게 접속 시 안내가 뜹니다.
- 채팅 입력창에 이미지를 **붙여넣기·끌어놓기**, 또는 채팅 컨트롤의 **이미지 버튼**으로 고르기. 웹페이지에서 그림만 복사하면 주소로 링크합니다.
- 서버의 `uploaded-chat-images` 폴더(설정에서 변경, Chat Images와 같은 기본값)에 올립니다. 1.5MB 넘는 이미지는 해상도를 유지한 WebP로 줄여서 올립니다(4MB 스크린샷 약 1초).
- 입력창 위에 미리보기가 쌓이고 ×로 뺄 수 있습니다. 업로드 중에도 입력창은 잠기지 않습니다.
- Enter: 글 없이 누르면 그림만 전송(채팅 컨트롤의 메시지 공개 범위를 따름), 글이 있으면 그림 아래에 글. 업로드가 덜 끝났으면 끝난 뒤 전송합니다. 주사위 굴림(`/r`)에는 붙지 않고 미리보기에 남습니다. 잡담·귓속말에는 붙습니다.
- `!ci|https://…/그림.png!` 처럼 쓰면 그 자리에 그림이 들어갑니다(Chat Images 문법).
- 채팅의 그림을 누르면 크게 보기 창(공유 가능). Chat Images로 만든 예전 메시지도 같은 모양·같은 동작입니다(메시지 마크업 호환).
- 사이드바를 접은 상태(입력창이 오른쪽 아래로 옮겨진 상태)에서도 됩니다.
- 파일 업로드 권한(설정 → 권한 구성 → 파일 업로드)이 없는 사용자는 버튼이 안 보이고, 붙여넣으면 안내가 뜹니다. Foundry 기본값은 신뢰하는 플레이어 이상입니다.
- 설정: "채팅 이미지 첨부"(월드), "채팅 이미지 업로드 폴더"(월드, GM), "이미지 첨부 버튼 표시"(개인).
- API: `game.modules.get("gatos-chat-tools").api.images` — `addFiles(files)`, `pending`, `clear()`.

### Chat Images 호환 패치 (0.3.2)
Chat Images 모듈을 아직 켜 둔 월드용입니다. Chat Images 파일은 건드리지 않습니다. 아래 무한로딩 항목은 v13용 Chat Images 3.3 기준이며, v14의 리치 텍스트 입력창에서는 Chat Images 자체가 동작하지 않을 수 있으니 이 모듈의 이미지 첨부 기능을 쓰는 것을 권합니다.
- **무한로딩 해결**: Chat Images는 v13에서 `.chat-controls`를 찾지만 v13.351은 `#chat-controls`라서 업로드 영역이 안 생기고, 붙여넣으면 입력창을 잠근 채 멈췄습니다. 업로드 영역을 `#chat-controls` 앞에 만들고, 리스너를 접속 직후 한 번만 붙입니다.
- **훅 디버그 로그 끔**: Chat Images가 시작할 때 모든 사람의 `CONFIG.debug.hooks`를 켜 두는 것을 끕니다.
- **큰 스크린샷 미리 줄이기**: 1.5MB 넘는 이미지를 WebP로 한 번 변환해 넘깁니다(약 30초 → 약 2초).
- 사이드바를 접은 상태에서는 붙여넣기가 안 됩니다(Chat Images 자체 한계).
- 설정 "Chat Images 호환 패치"(월드, 기본 켜짐)로 끌 수 있습니다.

## 참고
- 아카이브 삭제는 기본적으로 목록에서만 지웁니다. "파일 내용도 비우기"를 체크해도 빈 파일은 서버에 남습니다(필요하면 폴더에서 직접 삭제).
- 아카이브 JSON 파일은 로그인한 사용자라면 URL로 직접 받을 수도 있으므로, 비밀 메시지 숨김은 UI 수준의 가림입니다.
- API: `saveArchive({name, from, to, deleteAfter})`, `deleteMessagesInRange({from, to})`, `getIndex()`, `loadArchive(entry)`, `toText(messages)`, `toHTML(messages)` 등을 `game.modules.get("gatos-chat-tools").api` 에서 쓸 수 있습니다.

## 아카이브 JSON 형식 (v2, 모듈 0.2.0부터)
- 머리말: `module`, `version: 2`, `id`, `name`, `world`, `worldTitle`, `system`, `createdAt`, `createdBy`, `rangeFrom`/`rangeTo`, `from`/`to`, `count`, `messages`. 다른 모듈이 필드를 더할 수 있습니다(예: Gato's Visual Novel의 `vn`).
- 메시지: `id`, `timestamp`, `user`, `userId`, `color`, `alias`, `img`(카드 포트레잇), `imgLabel`(포트레잇 공급자가 준 이름표, 예: 표정 이름), `actor`, `token`, `flavor`, `content`, `html`(렌더된 본문), `whisper`, `whisperNames`, `blind`, `chitchat`, `highlight`, `sessionMarker`, `isRoll`, `rolls`, `type`, `style`. v1 아카이브에는 `imgLabel`이 없습니다.
- 0.3.0부터 머리말에 선택적으로 `session`({number, title, startedAt, endedAt}), `auto`, `merged`, `imported`가 붙습니다.

## 확장 지점 (0.2.0)
다른 모듈(Gato's Visual Novel 등)이 쓰는 API와 훅입니다. 이 모듈 단독 동작에는 영향이 없습니다.
- `api.registerPortraitProvider(fn)` — `fn(message)`가 이미지 경로 또는 `{img, label}`을 돌려주면 카드·뷰어·아카이브 포트레잇으로 우선 사용합니다. null이면 기존 규칙(토큰 → 액터).
- `api.lookupPortrait(speaker)`, `api.renderMessageContent(message)`, `api.htmlToText(html)`, `api.absoluteUrl(path)`, `api.buildBundle(messages, meta, mode)`, `api.EXPORT_CSS`
- `gctSerializeMessage(message, data)` — 직렬화 끝에서 `data`에 필드 추가.
- `gctArchiveHeader(archive)` — 아카이브 저장 직전 머리말에 필드 추가.
- `gctSpeakerBarMounted(bar)`, `gctSpeakerBarResolve(info)`(`info.img` 교체 가능), `gctSpeakerBarUpdated(bar, info)` — 발화자 바.
- `gctSpeakerResolved(message, data, options, userId)` — `preCreateChatMessage`에서 발화자 고정 처리가 끝난 뒤(고정이 없어도) 항상 호출.
- `gctExportRender(doc, ctx)` — 내보낼 HTML을 `DOMParser` 문서로 고칠 수 있음. 모든 모드. `<article data-message-id>`로 메시지와 짝지음.
- `gctSessionStarted(session)`, `gctSessionEnded(session, entry)`, `gctBookmarksChanged(ids, on)` (0.3.0).
- 메시지 생성 옵션 `{gctDuplicate: true}`: 복제본은 발화자 고정·포트레잇 재고정을 건너뜁니다(`gctSpeakerResolved`도 호출하지 않음).
- `gctExportLog(log, ctx)`, `gctExportBundle(bundle, ctx)` — zip/폴더 모드에서 로그 JSON(`bundle.logName` = `<페이지 이름>.log.json`, 0.3.1부터; 이전엔 `log.json`)과 번들 파일(`bundle.files`: 경로 → URL 문자열 / Blob / `{text}`)을 고침. `bundle.html`도 바꿀 수 있습니다. `ctx = { mode, meta, messages, relink(url, folder), bundle }`, `relink`는 파일을 번들에 넣고 상대 경로를 돌려줍니다.
- `api.registerViewerAction({ id, label, icon?, tooltip?, selection?, visible?, callback(messages, meta) })` — 아카이브 뷰어 툴바(지금 목록에 보이는 메시지)와 선택 막대(선택한 메시지)에 버튼을 추가합니다. `messages`는 렌더된 `html`이 채워진 직렬화 메시지, `meta = { title, source, selection }`. (0.3.1)
